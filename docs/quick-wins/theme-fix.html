Quick win 20 of 22 · Look and findability

What we're proposing

Correct the theme setting on inner pages so they use the Cambridge IVF colours already in the stylesheet, not NHS blue.

Why

The homepage uses Cambridge IVF’s dark pink, but every inner page has a blue hero, because the page carries the class “theme-- -ivf” instead of a valid theme name. The IVF theme rules are in the stylesheet and simply never apply. It’s a small fix for the CUH web team, and the site starts looking like one brand rather than two.
