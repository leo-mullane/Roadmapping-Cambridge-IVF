# Cambridge IVF website prototypes

Clickable prototypes of five bigger improvements to cambridge-ivf.nhs.uk and 22 quick wins, built from the phase 1 findings (see `data/ideas.json`). The Cambridge IVF design layer lives entirely in `src/css/theme.css`; empty that file to get the greyscale prototypes back.

Photography is Cambridge IVF's own, loaded from media.cuh.nhs.uk by `src/js/photos.js`, and only when the design layer is present. If an image can't load, an illustrated placeholder in the brand pinks shows instead. Photography © Cambridge IVF. If this is published on a public host, the pages and code are public too. Frutiger is licensed to the NHS, so Hind (Google Fonts) stands in.

## View
Open `docs/index.html` in a browser. No server or install needed.

To publish on GitHub Pages: push the folder to a repository, then Settings → Pages → Deploy from a branch → `main` / `/docs`. `docs/.nojekyll` is already there.

## Prototypes
1. Clear costs: `pages/costs.html` (`?package=pure|pureduo|plus|plusduo|multi|first` preselects a package)
2. Find your path: `pages/find-your-path.html` and `pages/your-journey.html`
3. Start today: `pages/start.html` (`?topic=` prefills the enquiry)
4. Proof you can trust: `pages/proof.html`
5. Self-pay services: `pages/egg-freezing.html` and `pages/self-pay.html`

Context is carried between pages with `?param=` and a sessionStorage fallback.

### Quick wins
`quick-wins/` holds 22 smaller changes, each on its own page with a Today / Proposed switch. They are generated by `tools/quick_wins.py` from the data in that file, with titles taken from `data/ideas.json`. Edit the script and run it rather than editing the generated pages.

## Build
```
python3 tools/quick_wins.py && node build-includes.js && node validate.js
```
Edit files in `src/`; `docs/` is generated. The prototype navigator (two tabs and the Notes switch) and the previous/next footer live in `src/includes/`. Behaviour is in `src/js/civf.js` (prototypes) and `src/js/wireframe.js` (shared patterns).

Requirements and their mapping to idea numbers: `requirements/requirements.md`.
